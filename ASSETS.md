# Assets

Every file under `public/` and every image under `blender/` and `docs/` is listed here with its source and licence. `test/assets.test.ts` fails when a file under `public/` has no row.

Shipped files are CC0 (public domain), CC BY 4.0 with the credit below, or made for this project. Nothing in this repository is Splice, Mixamo or any other licence that forbids redistributing the file.

## Private assets

The game hosted at https://rainline.openwebarcade.com also plays sounds licensed from Splice and shows a roadside cast of Adobe Mixamo characters in Beaver Run. Those licences allow them inside a finished game but not as files anyone can download, so they live in a private repository (`marginsystems/rainline-assets`) and are never committed here. The game loads them from the git-ignored `public/local/` folder when it is present; see the README.
